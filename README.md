# 一划相册

一划相册是一款面向 Android 手机的相册整理工具，适合照片、截图、视频、相似照片较多的用户。它通过推荐整理、批量删除、保留名单和最近删除等流程，帮助你用更低的决策成本整理手机相册，减少重复翻找和误删焦虑。

## 快速开始

1. 在手机浏览器中打开本页面，点击上方 APK 文件下载。
2. 下载完成后，点击安装包并允许浏览器安装未知来源应用。
3. 首次打开应用后，根据系统提示授予照片和视频访问权限。
4. 在首页选择推荐整理、批量删除、时间整理或相册整理。
5. 整理完成后，在最近删除中确认恢复或彻底清理。

## 产品介绍

一划相册围绕“快速判断、批量处理、二次确认”设计。用户可以按截图、视频、相似照片、重复照片等分类进入整理，也可以一张张滑动判断保留或删除。对不想再被推荐清理的照片，可以加入保留名单。删除前内容会先进入应用内最近删除，用户确认后再彻底清理，兼顾效率和安全感。

## 运行要求

- Android 11 及以上系统。
- 需要授予照片和视频访问权限。
- 安装 APK 时，手机可能需要开启“允许安装未知来源应用”。

## 注意事项

- 请从本页面下载最新安装包，避免安装来源不明的版本。
- 整理和删除照片前，请仔细确认待处理内容。
- 不同品牌手机的系统相册和最近删除展示方式可能略有差异。
